Базы 1С — исходники для чтения кода

Консультант читает код конфигурации (ошибки «Модуль(строка)», поиск по коду) из базы: выгрузите исходники один раз и после обновления конфигурации. В базе должно стоять расширение консультанта. Опубликованную через ibsrv базу приложение остановит на время выгрузки и запустит снова.
