# Дата запрета изменения: как читать

Дата запрета изменения закрывает период. Если дата запрета — 30.09.2026, то документы с датой
**по 30.09.2026 включительно изменять, проводить и удалять НЕЛЬЗЯ**; документы с датой с 01.10.2026 — можно.

- «Общая дата» действует для всех разделов и объектов, кроме указанных отдельно.
- Дата может быть своя для пользователя или раздела — смотреть строку именно этого пользователя.
- Исправить документ закрытого периода: попросить ответственного (главного бухгалтера) временно сдвинуть
  дату запрета, либо внести исправление текущим периодом (исправительный документ, корректировка).
- Где смотреть: отчёт «Даты запрета изменения» (инструмент report_run, Отчет.ДатыЗапретаИзменения).
