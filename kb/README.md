# База знаний ИИ-консультанта

Сюда кладутся материалы, по которым ищет инструмент `kb_search`:

- инструкции, регламенты, ответы на частые вопросы — в корень или подкаталоги (`.md`, `.txt`, `.docx`, `.pdf`, `.html`);
- решённые обращения — в `tickets/`, по файлу на обращение: симптом, причина, решение.

Индекс строится в памяти при первом поиске и пересобирается при изменении файлов. Поиск лексический
(BM25 по основам слов), без внешних сервисов. Этот README в поиск не попадает.

Файлы в `tickets/` с пометкой «пример» — разборы, сделанные на тестовой базе при разработке консультанта.
